# 表达式语言语义规范 v1

版本：2026-09-10-v1。状态：本文件描述 `mat01` 包当前已实现的语义，是本版本的可检查契约。超出本文件范围的能力一律视为不支持，遇到时必须给出明确错误，不得按 Python 或其他语言的习惯静默解释。

## 范围

本版本只支持**表达式求值**：整数字面量、布尔与空值字面量、括号、一元运算、基本二元算术/比较/相等运算、`and`/`or`/`not` 短路逻辑、显式输入变量，以及宿主显式注册后才能调用的函数。

本版本**不支持**（遇到即报编译错误）：字符串字面量、浮点字面量、赋值、语句、控制流、列表/字典等集合、属性访问、下标、链式比较（如 `a < b < c`）、闭包、模块导入。语言不按 Python 表达式求值，表达式默认不具备文件、网络、进程或反射能力。

## 词法

- 空白：空格、制表符、换行可出现在任意记号之间，仅用于分隔。
- 注释：`#` 到行尾为注释。
- 整数字面量：一个以上十进制数字（`0`、`42`、`007`）。不支持其他进制、浮点或字符串字面量。
- 标识符：`[A-Za-z_][A-Za-z0-9_]*`，用于变量名与函数名。
- 关键字（保留，不能作为变量名或函数名）：`and`、`or`、`not`、`true`、`false`、`null`。
- 运算符与标点：`+ - * / % ( ) , < <= > >= == !=`。
- 其他字符（包括 `'`、`"`、`.`、`=`、`!`、`&`、`|` 等）是词法错误，报错信息指出所在位置；对常见误用（字符串引号、小数点、赋值号）给出"不支持"的明确提示。

## 语法

优先级从高到低：

| 优先级 | 结构 | 结合性 |
|---|---|---|
| 1 | 字面量、变量、函数调用、`( 表达式 )` | — |
| 2 | 一元 `-`（取负） | 右结合 |
| 3 | `*` `/` `%` | 左结合 |
| 4 | `+` `-` | 左结合 |
| 5 | `<` `<=` `>` `>=` `==` `!=` | 不结合（只允许一个比较符） |
| 6 | `not` | 右结合 |
| 7 | `and` | 左结合 |
| 8 | `or` | 左结合 |

一个编译单元是恰好一个表达式；表达式之外的多余内容（包括第二个表达式或语句）是语法错误。

## 值类型

运行时只有三种值类型：

- **int**：任意精度整数（不溢出）。
- **bool**：`true` / `false`。bool 与 int 是**不同类型**；`1 == true` 为假，对 bool 做算术是类型错误。
- **null**：空值，写作 `null`。只参与相等比较和函数传参。

宿主通过 `evaluate` 传入的变量值只允许是这三种类型对应的 Python 值（`int` 且非 `bool`、`bool`、`None`），否则在求值开始前抛出 `TypeError`（宿主调用错误，不是脚本错误）。

## 求值顺序

- 二元运算先求左操作数，再求右操作数，均严格求值。
- 函数调用的参数从左到右依次求值。
- `and` / `or` 短路：`左 and 右` 在左侧为 `false` 时**不求值右侧**；`左 or 右` 在左侧为 `true` 时不求值右侧。右侧的函数调用因此不会执行。
- 比较运算不结合：`a < b < c` 是语法错误。

## 名称查找

- **变量**：来自 `Program.evaluate(variables=...)` 传入的映射，按名查找。引用未传入的变量是执行错误 `UnboundNameError`。
- **函数**：来自 `Environment.register_function` 显式注册。调用未注册的函数名是执行错误 `UnboundNameError`。
- 变量与函数是两个独立命名空间，可以同名互不影响。
- 不存在全局内置函数、内置常量或隐式环境；环境为空时任何函数调用都失败。

## 函数与参数绑定

- 宿主通过 `Environment.register_function(name, func, arity=...)` 注册 Python 可调用对象。
- `arity` 可以是整数（精确参数个数）或 `(min, max)` 元组；省略时从可调用对象的签名推断，无法推断则抛出 `ValueError`。
- 调用时参数个数不在声明范围内是执行错误 `ArityError`。
- 宿主函数返回的值必须是三种值类型之一，否则是执行错误 `TypeMismatchError`。
- 宿主函数抛出的任何 Python 异常被包装为执行错误 `HostFunctionError`，原异常通过 `__cause__` 保留；脚本位置指向调用处。这属于**宿主调用错误**，与脚本自身的类型错误区分。

## 类型规则

| 运算 | 操作数要求 | 结果 |
|---|---|---|
| `+ - * / %`、一元 `-` | 两个都是 int（bool 不算 int） | int |
| `< <= > >=` | 两个都是 int | bool |
| `==` `!=` | 任意类型；类型不同则不相等 | bool |
| `and` `or` `not` | 必须是 bool，不做真值转换 | bool |

- `/` 为向下取整除法，`%` 为取模（符号跟随除数，与 Python 一致）。除数为零是执行错误 `DivisionByZeroError`。
- 无隐式类型转换，无真值语义：`not 1`、`1 and true`、`null or false` 都是类型错误。
- 违反上表是执行错误 `TypeMismatchError`，错误位置指向运算符。

## 错误模型

所有错误都携带 `Diagnostic` 诊断对象。错误分两大类：

- **编译错误 `CompileError`**：词法与语法问题，在 `compile_source` 阶段抛出，求值不会发生。
- **执行错误 `EvaluationError`**：求值阶段抛出，子类包括
  `TypeMismatchError`（类型不匹配）、`UnboundNameError`（未绑定变量或未注册函数）、`ArityError`（参数数量错误）、`HostFunctionError`（宿主函数异常）、`DivisionByZeroError`（除数为零）。

宿主 API 误用（注册非法函数名、传入非法变量值等）抛出普通 `ValueError` / `TypeError`，不属于脚本错误。

## 诊断对象

```python
Diagnostic(message, position=SourcePosition(offset, line, column), source_name)
```

- `offset`：从 0 开始的字符偏移；`line`、`column`：从 1 开始的行列。
- 词法/语法错误指向出错记号；类型错误指向运算符；未绑定名称指向名称出现处；宿主函数异常指向调用处函数名。
- 所有错误对象（`CompileError`、`EvaluationError` 及其子类）都有 `.diagnostic` 属性；`str(error)` 形如 `<name>:3:7: message`。
